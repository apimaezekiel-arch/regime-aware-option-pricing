# Data availability
This folder contains no proprietary observations. The introductory notebook synthesizes prices for instruction only.

For empirical work, obtain historical option quotes legally from an exchange, broker, or licensed vendor. Required fields: quote timestamp, expiry, type, strike, bid/ask, underlying price, rate/dividend information. Do not claim yfinance current-chain snapshots represent historical option observations.

Avoid committing downloaded data with restricted redistribution terms; keep raw data locally and use reproducible extraction scripts where licenses allow.
